# About

sverige aims to be a minimal and flexible system for developers, tinkerers, and people who need their environment to help them understand how an operating system is actually put together. sverige actually makes it rewarding to build, be it on your own projects or working on the system itself. A clean set of upstream sources, clear up-front configuration, and complete manual control make the system work *for* instead of *against* the builder.

## Features

* **Source-based Linux assembly with up-front configuration[span_2](start_span)[span_2](end_span).**  
  Common tasks like system compilation and toolchain isolation follow a flexible yet deterministic and comprehensible path.

* **Upstream transparency done properly.**  
  Mixing in packages directly from official upstream sources (`gnu.org`, `kernel.org`, `freedesktop.org`) or even configurations that you wrote yourself is entirely up to you.

* **For developers — we expect users to take part in the development[span_3](start_span)[span_3](end_span).**  
  Whether it is refining the guide, writing documentation for the upcoming Suomi book, or adapting the build sequence, sverige relies on active user ownership. The project welcomes contributions, suggestions, and improvements from anyone building it.

---

## Project Status

* **sverige (Base):** Complete. Provides a fully documented, manual 33-step build sequence for a functional command-line base system.
* **Suomi (Extended):** Incomplete. Extended components like graphics and audio stacks are currently under planning and development.
